# claude-codex-bridge

[English version](README.md)

Плагин Claude Code, с которым **Claude Code** и **Codex** (агент в десктопном приложении ChatGPT/Codex) общаются напрямую: без копирования между окнами, без общего файла с заметками и без открытия чатов только для того, чтобы подтолкнуть агента.

- **Claude → Codex.** Claude пишет в чат Codex по теме. Открытый чат берёт сообщение сразу, закрытый плагин сам открывает в приложении Codex — работу видно.
- **Codex → Claude.** Для ответа ничего особенного не нужно: его получит сеанс Claude, который писал в чат. Чтобы обратиться к конкретному сеансу, Codex заканчивает ход словами «Для Claude (чат «Название»): …» — этот сеанс просыпается примерно через секунду и отвечает в тот же чат. «Для Claude: …» без названия получит сеанс, который последним писал в этот чат.
- **Ожидание не грузит процессор.** Слушатель спит на событиях файлов macOS (kqueue) и просыпается, только когда Codex пишет в чат.

Неофициальный инструмент, не связан с Anthropic или OpenAI.

## Что нужно

- macOS.
- Десктопное приложение Codex (ChatGPT.app с Codex): команду `codex queue` даёт только встроенный в него CLI. Отдельно установленного `codex` мало.
- Claude Code (CLI или вкладка Code в приложении Claude).
- `python3` и `git` в PATH (подходят стандартные инструменты разработчика macOS).

## Установка

В Claude Code:

```
/plugin marketplace add Dmitry-rman/claude-codex-bridge
/plugin install codex-chat@claude-codex-bridge
/codex-chat:setup
```

`/codex-chat:setup` показывает правило для Codex и после вашего согласия добавляет его в `~/.codex/AGENTS.md` между служебными комментариями. Повторный запуск обновляет этот блок, а не дублирует. Новые чаты Codex читают правило сами; уже открытому чату скажите перечитать `~/.codex/AGENTS.md`.

После установки откройте новый сеанс Claude, чтобы подхватился хук.

## Как пользоваться

Просто скажите Claude: «передай Codex в чат про титры, что я выбрал вариант Б, и дождись, когда он закончит». Claude найдёт чат, отправит сообщение и проснётся от ответа Codex.

Codex: «ответь Claude в сеанс «Меню», что экспорт готов». Codex одной командой получает список сеансов Claude этого проекта и заканчивает ход словами «Для Claude (чат «Меню»): …».

Скрипт можно запускать и вручную из папки проекта:

```bash
python3 ~/.claude/codex-chat/codex_chat.py list       # чаты Codex: свободен/работает, открыт/закрыт
python3 ~/.claude/codex-chat/codex_chat.py sessions   # сеансы Claude (адреса для Codex)
python3 ~/.claude/codex-chat/codex_chat.py send "титры" "Выбран вариант Б, внеси его"
```

Настройки (переменные окружения):

| Переменная | Что делает |
|---|---|
| `CODEX_CHAT_HEADLESS=0` | Не запускать чат в фоне, даже если приложение не смогло его открыть: сообщение ждёт, пока вы откроете чат. |
| `CODEX_CHAT_LANG=en\|ru` | Язык подписи Claude и правила для Codex. По умолчанию — язык системы. |
| `CODEX_BIN` | Путь к CLI Codex с командой `queue` (по умолчанию — встроенный в ChatGPT.app). |

## Как это устроено

- На каждый загруженный в приложение чат Codex держит блокировку записи (`~/.codex/thread-writer-locks`). Если её держит приложение, сообщение идёт через `codex queue`. Закрытый чат сначала открывается в приложении ссылкой `codex://threads/<id>` (окно Codex может на него переключиться), потом сообщение ставится в очередь. Только если приложение не смогло его загрузить, плагин запускает `codex exec resume <чат>` в фоне (песочница `workspace-write`, без запросов подтверждения); пока он работает, приложение показывает чат как открытый в другом приложении.
- Каждый законченный ход Codex пишется в журнал чата в `~/.codex/sessions`. Ждать ответ значит ждать там следующий `task_complete`.
- Названия сеансов Claude берутся из `~/.claude/sessions/*.json`. `send` запоминает, какой сеанс последним писал в каждый чат (`~/.claude/codex-chat/senders.json`): ответ без названия уходит ему, а сеанс, который ждёт через `send --wait`, хук повторно не будит.
- Хук `Stop` плагина запускается с `asyncRewake` после каждого хода Claude: один слушатель на сеанс, предыдущий заменяется, позиции чтения сохраняются, так что между ними ничего не теряется. Подходящее сообщение печатается, хук выходит с кодом 2, и сеанс просыпается.

## Ограничения

- **Внутренние форматы.** База состояния, журналы и блокировки Codex, файлы сеансов Claude — не публичный API. Обновление приложений может сломать плагин; тогда он остановится с понятным сообщением, а не будет угадывать.
- **Запасной фоновый запуск.** Он загружает всю историю чата: для длинного чата это минуты и много токенов Codex, а чат в приложении на это время заблокирован. `CODEX_CHAT_HEADLESS=0` отключает его совсем.
- **Идущий ход не прерывается.** Сообщение в занятый чат обрабатывается после текущего хода.
- **Конфиденциальность.** Слушатель читает журналы чатов Codex текущего проекта только на вашем компьютере и никуда их не отправляет.
- **Согласие.** Сообщения агентов подписаны как сообщения агента; оба правила говорят, что они не заменяют согласие пользователя.
- Сеанс Claude будится, только пока он открыт. Сообщения, пришедшие без него, остаются в чате Codex (`read`).
